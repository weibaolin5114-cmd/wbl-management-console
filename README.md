# B 端管理系统通用界面

这是一套可以直接用浏览器打开的后台界面。做新系统或原型时，先沿用这里的布局、按钮、表格和弹窗，再换成自己的菜单和页面文字。

页面里的查询、保存、新增，只在当前浏览器里演示，没有连接账号服务。

## 先在自己电脑上看

1. 打开仓库页面，点绿色的 **Code**，再点 **Download ZIP**。
2. 把压缩包解压到一个文件夹。
3. 进入解压后的文件夹，双击 `index.html`。登录页是 `login.html`。
4. 改完文件后，回到浏览器，按 `F5` 刷新，才能看到新效果。

## 改主色

全系统只改一个地方：`css/tokens.css`。

用记事本或编辑器打开它，找到这一行：

```css
--color-primary: #2A8371;
```

`#2A8371` 是现在的绿色。把这 6 位颜色换成你要的颜色，保存。

例如改成蓝色：

```css
--color-primary: #1677ff;
```

保存后刷新浏览器。这些地方会一起变，不用逐个去改：

- 主按钮
- 侧栏里选中的菜单
- 文字链接
- 浅色底和浅色边框

悬停色、按下色不用另改，它们会按主色自动算出来。

## 改系统名称

全系统只改一个地方：`js/brand.js`。

打开后会看到：

```javascript
window.BRAND = {
  name: "管理系统",
  logo: "",
  userName: "管理员"
};
```

把 `name` 后面的文字换成新名称。引号要保留。

例如：

```javascript
window.BRAND = {
  name: "库存管理",
  logo: "",
  userName: "管理员"
};
```

保存并刷新后，侧栏左上角和登录页大标题都会变成「库存管理」。

## 改标识

标识也只改 `js/brand.js` 里的 `logo`。仓库里没有附带标识图片。

`logo` 为空时，侧栏和登录页只留一个空位，不显示图片：

```javascript
logo: "",
```

要显示图片时：

1. 在 `index.html` 旁边新建一个文件夹，命名为 `assets`。
2. 把标识图片放进去，例如 `logo.png`。
3. 把 `logo` 改成这张图片的相对路径。

```javascript
window.BRAND = {
  name: "库存管理",
  logo: "assets/logo.png",
  userName: "管理员"
};
```

保存并刷新。侧栏和登录页会显示同一张图。图片建议用横向、底色透明的图。路径写错时，空位里会显示不出图片，请检查文件名和文件夹名是否一致，包括大小写。

不要把标识地址写进各个页面。页面上的空位会自动读取 `logo`。

## 改顶栏用户名

还是 `js/brand.js` 里的 `userName`。

```javascript
userName: "张敏"
```

顶栏右侧会显示「张敏」，圆头像里显示第一个字「张」。

## 改侧栏菜单

菜单在 `js/chrome.js` 开头的 `MENU` 里。每一项有三个常用字段：

- `label`：侧栏上看到的文字
- `href`：点击后打开的页面
- `id`：用来标出当前页，需要和页面对应

例如把「列表」改成「订单」：

```javascript
{ id: "list", href: "list.html", label: "订单", icon: "..." }
```

`icon` 是图标，不改文字时可以不动。改完保存并刷新。

新增一个菜单时，照着旁边的一行复制，改 `id`、`href`、`label`，并准备一个同名的页面文件。

## 页面分别是什么

| 文件 | 做什么 |
| --- | --- |
| `login.html` | 登录。右下角可以进忘记密码 |
| `forgot-password.html` | 忘记密码：先填账号，再设新密码 |
| `change-password.html` | 首次登录时修改密码 |
| `index.html` | 概览 |
| `list.html` | 筛选、工具栏、表格、分页 |
| `form.html` | 表单 |
| `detail.html` | 详情 |
| `logs.html` | 操作日志 |
| `settings.html` | 系统设置：登录方式、密码策略、基本信息 |
| `users.html` | 用户管理 |
| `roles.html` | 角色和权限 |

登录方式里的「图形验证码」开关，在 `settings.html` 里修改。它只记在当前这次浏览器访问里，并作用到登录页和忘记密码页。关掉浏览器再打开，会回到默认开启。

## 做一套新系统时怎么用

1. 复制整个文件夹。
2. 按上面的步骤改主色、系统名称、标识。
3. 在 `js/chrome.js` 里改菜单名称。
4. 打开对应的 `.html`，把页面上的示例文字、表格列和表单字段换成新系统的内容。
5. 用浏览器打开 `index.html` 检查。

样式尽量留在 `css` 文件夹里，不要在每个页面里单独写一套颜色。
