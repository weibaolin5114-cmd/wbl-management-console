# B 端管理系统通用界面

这是一套可直接打开的后台界面参考。做新系统或原型时，保留布局、密度和组件，替换菜单与页面内容。

## 页面

| 文件 | 内容 |
| --- | --- |
| `login.html` | 登录，含忘记密码入口 |
| `forgot-password.html` | 忘记密码 |
| `change-password.html` | 首次登录修改密码 |
| `index.html` | 概览 |
| `list.html` | 筛选、工具栏、表格、分页 |
| `form.html` | 表单 |
| `detail.html` | 详情 |
| `logs.html` | 操作日志 |
| `settings.html` | 系统设置，含登录方式、密码策略、基本信息 |
| `users.html` | 用户管理 |
| `roles.html` | 角色管理 |

用浏览器打开 `index.html` 或 `login.html` 即可查看。侧栏菜单在 `js/chrome.js`。登录方式里的验证码开关保存在当前浏览器会话，并作用到登录页和忘记密码页。这些页面只演示界面，不连接账号服务。

## 改主色

只改 `css/tokens.css` 里的 `--color-primary`。按钮、菜单选中、链接、标签浅底会跟着变。

## 改名称和标识

只改 `js/brand.js`。

- `name`：侧栏和登录页标题。
- `logo`：标识图片地址。留空时不显示图片，只保留一个空位。填入地址后，侧栏和登录页一起显示这张图。
- `userName`：顶栏当前用户。头像取名称的第一个字。

仓库里不包含标识文件。需要图片时，把文件放到自己的目录，再把 `logo` 写成该文件的相对路径。
